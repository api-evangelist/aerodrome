# Aerodrome Finance

> Aerodrome is the central trading and liquidity marketplace on the Base network — a next-generation MetaDEX (AMM inspired by Solidly / Velodrome) that combines a vote-escrow (ve(3,3)) token model, gauge-directed AERO emissions, and both basic (vAMM/sAMM) and concentrated-liquidity (Slipstream) pools. It is a smart-contract protocol: there is no hosted REST API — developers integrate via onchain contracts, the shared "Sugar" SDK, and GraphQL subgraphs.

## Notes for agents
- The SDK builds UNSIGNED transactions ({from,to,data,value}); it never signs or holds keys. Approvals are emitted first, then the main call.
- All state changes are wallet-signed onchain transactions on Base — there is no API key / OAuth surface.
- Security posture (audits + bug bounty) is shared with Velodrome; review https://aerodrome.finance/security before integrating.
